# 鲁迅 & 周作人全集 中文文学语料库

包含鲁迅、周作人两位作家完整作品的清洗后纯文本语料，适用于NLP研究、文本风格分析、大模型训练、文学研究等用途。
基于本语料完成了词频统计、词汇丰富度分析、句式特征对比与词云可视化，量化呈现两位作家的语言风格差异。

## 清洗说明
1.  基础文本处理：已去除广告、页码、乱码、多余空行、无关符号，保留完整原文。
2.  分词与过滤：
    -  对文本进行分词处理，词语以空格分隔；
    -  自定义停用词表，过滤无实义虚词、语气词、单字等干扰词汇；
    -  输出 `luxun_clean.txt` / `zhouzuoren_clean.txt` 两份标准分词语料。

## 语料分析说明
本项目在清洗语料基础上，完成了多维度量化对比分析：

1.  **基础指标统计**
    -  总句数、总词数、词种数（词汇丰富度）；
    -  平均句长、句长分布（短句/中句/长句占比）；
    -  采用占比和千词密度为标准，消除语料体量差异，客观对比文本特征。

2.  **词汇特征分析**
    -  高频词TOP500统计，以千词密度展示核心用词偏好；
    -  共用词与独有词对比，区分通用表达与个人特色词汇；
    -  主题关键词密度统计，量化社会批判、生活闲情等创作取向差异。

3.  **可视化呈现**
    -  基于有效词汇生成词云图，直观呈现高频词分布；
    -  辅助解读两位作家的语言风格：鲁迅词云高频词多与批判、抗争相关，体现其冷峻犀利的文风；周作人词云则偏向日常、闲适类词汇，呼应其冲淡平和的散文风格。
